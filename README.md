# 변혜인 포트폴리오

Figma 디자인을 기준으로 제작하는 정적 포트폴리오 사이트다.

## 기술 환경

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## 폴더 구조

```text
.
├─ index.html
├─ assets/
│  ├─ css/styles.css
│  ├─ js/main.js
│  ├─ images/
│  │  ├─ hero/
│  │  ├─ profile/
│  │  ├─ skills/
│  │  ├─ projects/
│  │  ├─ works/
│  │  └─ icons/
│  └─ files/
└─ README.md
```

현재는 1단계 기본 구조만 구성된 상태다. 디자인 에셋과 기능은 후속 단계에서 추가한다.
