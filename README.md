# 변혜인 포트폴리오

웹 디자인과 퍼블리싱, 영상 작업을 소개하는 개인 포트폴리오 웹사이트입니다.

Figma에서 직접 디자인한 UI를 바탕으로, 프로젝트와 작업물의 의도와 결과가 자연스럽게 전달될 수 있도록 구현하고 있습니다. 레이아웃과 타이포그래피는 물론, 콘텐츠의 흐름을 돕는 인터랙션과 애니메이션까지 함께 구성합니다.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## 주요 구성

- **Home** — 포트폴리오의 메인 비주얼과 간단한 소개
- **About** — 프로필, 디자인·퍼블리싱 역량, 보유 기술
- **Web Projects** — 웹 디자인 및 퍼블리싱 프로젝트
- **Video Projects** — 광고 영상, 영상 편집, 모션그래픽 작업
- **Contact** — 연락처와 포트폴리오 관련 링크

## Design & Development

디자인은 Figma를 기반으로 제작합니다. 시각적인 완성도에 그치지 않고, 사용자가 작업물을 편하게 탐색하고 이해할 수 있는 경험을 고민하며 개발합니다.

이 포트폴리오 사이트는 새로운 프로젝트와 작업물이 추가될 때마다 지속적으로 업데이트하고 있습니다.
